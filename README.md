# Urdu to English Speech Translator

A Streamlit web app that takes spoken Urdu audio as input, translates it to English, 
and displays the output in real time.

## What it does
- Captures or accepts Urdu speech input
- Processes audio through a speech recognition pipeline
- Translates Urdu text to English using NLP
- Displays the translated output via a clean Streamlit interface

## Built with
- Python
- Streamlit
- SpeechRecognition
- Google Translate API
- gTTS / audio processing libraries

## How to run
```bash
pip install -r requirements.txt
streamlit run app.py
```
